# Personal Projects and Interests

Outside of work, I spend a lot of time building technical projects, learning new skills and taking on challenges that push me outside my comfort zone.

## LifeRAG — AI CV Chatbot

I built LifeRAG as an interactive version of my professional profile.

The idea was to move beyond the limitations of a traditional two-page CV and allow recruiters or hiring managers to ask questions about my experience, projects and technical background.

The application uses Retrieval-Augmented Generation (RAG) to search a curated knowledge base before generating answers, helping keep responses grounded in source material.

The project has also given me practical experience with deploying an AI application publicly, structuring a knowledge base, vector search, prompt design, source attribution and logging user interactions.

## Full-Stack Messaging Application

I built a full-stack instant-messaging application inspired by products such as WhatsApp.

The application includes:

- React-based front end
- REST API backend
- User authentication
- Conversation management
- Real-time messaging functionality

The main reason for building it was to deepen my understanding of how a complete application works across the front end, backend, APIs, authentication and real-time communication.

I am also interested in taking the underlying messaging platform further. Two concepts I have explored are:

- A video-sharing experience inspired by Snapchat
- A communication product designed around reducing reliance on phones and overall screen time

## German

Since moving away from Germany, I have made a conscious effort to maintain the language rather than allow the skill to disappear.

For me, learning German has been as much about persistence as aptitude: maintaining a language requires consistent practice even when it is no longer necessary for day-to-day life.

## Public Speaking

Public speaking did not come naturally to me, so I enrolled myself on a two-day public-speaking course specifically to address the anxiety and nerves I experienced when presenting.

The course significantly reduced my anxiety around presenting, although it did not eliminate it completely.

I see this as an example of how I approach development areas: if something is uncomfortable but important, I would rather work directly on it than avoid it.
